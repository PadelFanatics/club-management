# Feedback Portal Reference — Vision

Use the self-hosted Feedback Portal as a reference for support, feedback, roadmap, changelog, tenant scoping, encrypted AI settings and approval-gated agent actions. Keep it separate from the Padel domain backend until an integration boundary is designed and tested.

## Success measures

- Portal runs in a disposable environment.
- Authentication and database boundaries are understood.
- Selected patterns are documented.
- No secrets or live data are connected.

## Agent role

Inspect, compare and propose selective adaptations. Never merge repositories or connect production databases without an explicit architecture decision.
