# Seven-Day Cross-Project $10K Sprint

## Day 1 — Choose and package

- Keep Padel Club Management as the primary recurring offer.
- Create the club plan table and $1/30-day trial.
- Define limited AI credits and optional setup packages.
- Write one clear promise for club owners.
- List all other projects as traffic, content, affiliate, commerce or partner assets.

## Day 2 — Build the conversion system

- Create the PageBuilder landing page.
- Create application/signup form.
- Create trial activation and card flow.
- Create CRM pipeline in Scale.gg/Client Services Suite.
- Create calendar, invoice and DocSigner steps.
- Prepare the seven-day upgrade email.

## Day 3 — Build the proof/demo

- Prepare the Padel club-management demo.
- Show booking, rankings, matches, tournaments, club profile and player flow.
- Explain credit wallet and club-owned Kick/VOD setup.
- Prepare Shopify store and supplier-commerce explanation.
- Record the first setup-training video.

## Day 4 — Build the lead list

- Use Lead Finder for global English-speaking padel clubs.
- Segment by court count and country.
- Identify owner/operator and contact details.
- Add prospects to PipeLeads CRM.
- Prepare a short personalised club audit.

## Day 5 — Outreach and content

- Publish a Pattaya at 53 founder update.
- Stream a Kick session with the GoPro.
- Repurpose the session into short clips.
- Send personalised club audits.
- Publish one free challenge or club-growth diagnostic through Profit From Challenges.
- Add compliant affiliate disclosures where affiliate links are used.

## Day 6 — Calls and pilots

- Run club demos.
- Offer $1/30-day trials.
- Sell optional setup packages.
- Connect AI wallet/provider path.
- Choose the first case-study club.
- Keep CQFI/Dr Cari and other partnership offers in a separate follow-up lane unless ready.

## Day 7 — Install and measure

- Configure the first club.
- Invite staff and players.
- Launch first campaign.
- Track trial activation, players invited, AI credits used and setup revenue.
- Review Scale.gg/PageBuilder campaign data with authenticated access.
- Decide what receives the next seven days of build time.

## Metrics

- Qualified clubs added.
- Outreach sent.
- Calls booked.
- Trials activated.
- Setup packages sold.
- Monthly recurring revenue.
- Credit-pack purchases.
- Player signups.
- Shopify/referral sales.
- Content outputs per live stream.
