# Other Projects — $10K/Month

## Purpose

This is the cross-project revenue archive for the projects discussed alongside Padel Club Management. It preserves the opportunity map, affiliate promotions, content engines, Scale.gg assets, and the seven-day operating focus before a computer reboot.

## Core rule

Do not build all projects at once. Choose one primary cash engine, use the other projects as traffic, proof, affiliate, content or upsell assets.

## Recommended primary cash engine

Padel Club Management / Padel Club Scale remains the strongest productised recurring-revenue candidate because it has an existing app, a club-management codebase, a public Padel Fanatics funnel, a credit-wallet model, club setup services, a Kick/VOD content workflow, Shopify commerce and clear B2B buyers.

## Revenue target

The practical path to $10,000/month is a combination of:

- club subscriptions;
- credit-wallet margin;
- setup packages;
- CRM/marketing add-ons;
- player upgrades;
- affiliate/equipment sales;
- Shopify/storefront margin;
- tournament kit and design sales;
- content/VOD services.

The first seven-day target is a working offer, prospect list, trials, setup sales and a case-study customer—not a guaranteed $10,000 MRR.
