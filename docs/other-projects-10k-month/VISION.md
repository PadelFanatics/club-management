The wider projects are leverage around the primary Padel Club Management build. They must supply leads, proof, content, affiliate revenue, commerce, partnerships or future upsells. They must not fragment the first 30-day execution sprint.

Help the Padel Club Management offer reach the first credible path toward $10,000 MRR within 30 days by producing reusable audience, trust, leads and monetisation assets.

## Fastest path

The Padel Club Management offer gets the main build time. The portfolio contributes one approved content or lead asset per work block, not a separate product build for every project.

## Agent rule

Each project gets one VISION.md and one bounded agent role only after its current purpose is clear. Do not create a large fleet of agents at the start. Start with report, then draft, then supervised action.
